# nfindley.com

Personal portfolio site for **Nicholas (Nick) Findley** — hands-on troubleshooter moving into tech.

🔗 **Live site:** [nfindley.com](https://nfindley.com)

## About

A single-page site covering my background, projects, and skills: software repair and builds (MeshSense), a solar-powered Meshtastic mesh network, electronics, and functional 3D-printed parts.

## Built with

- Hand-written HTML and CSS — no frameworks or build step
- Automatic light/dark mode and mobile-friendly layout
- Open Graph tags for link previews in iMessage and social apps
- Hosted on **Cloudflare Pages**, auto-deployed on every push to `main`
- Custom domain and email managed through Cloudflare DNS
